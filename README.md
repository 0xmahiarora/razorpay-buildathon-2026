# Razorpay SmartHaggle – AI‑Powered Agentic Commerce Workspace

An elite, single-viewport spatial application engine designed explicitly for the **Razorpay AI Buildathon**. This project demonstrates an autonomous conversational checkout module that actively prevents cart abandonment by negotiating with users dynamically to rescue merchant revenue, while enforcing strict corporate guardrails.

## 📖 Overview
SmartHaggle is a single‑viewport web app that demonstrates:
* **Autonomous Interaction Vector:** Real‑time price negotiation via an autonomous conversational assistant.
* **The Bar Adherence:** Enforces a hard‑coded 15% discount safety gate boundary requirement for all money actions.
* **Resilient Infrastructure:** A Local‑First offline sync engine that buffers transactions into LocalStorage arrays when the network drops and flushes them back to cloud APIs when connectivity returns.
* **Premium Spatial UX:** An immersive glass‑morphed UI built on a 3‑D matrix platform that warps and tilts dynamically based on mouse coordinate tracking, mirroring the official landing page aesthetic.

## ✨ Core Features
* **Inline receipt execution** – Rendered cleanly inside the terminal chat panel stream to eliminate intrusive pop-up overlays or screen transition drops.
* **Gated Offline Trigger** – Shshifted from artificial buttons to the minimal top navigation item "The Offer" to toggle offline isolation sandboxing seamlessly.
* **Persistent Structural Layout** – Scrollbar gutters are permanently locked onto layout boxes to completely prevent annoying interface layout-shifts on local server refreshes.
* **Enterprise Split‑Grid Architecture** – An optimized balancing grid splitting the left analytical product catalog and right conversational terminal log uniformly.

## 🛠️ Code Architecture & Core Tech Used
* **Frontend Design Layer:** HTML5 (Semantic Structure), CSS3 (Modern Flexbox Matrix, 3D Perspective Transforms).
* **Logical Engine Layer:** Vanilla JavaScript (Parallax Coordinate Math, Bounded Gate Assertions, local-first API Queue Managers).
* **Corporate Theme System:** Curated "Tokyo Midnight Cyber" styling variables matching Razorpay's internal design tokens.
